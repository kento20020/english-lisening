# 決めたことの記録

あとから「なぜこうしたのか」を確かめられるように、決めたことを新しい順に残します。

## 2026-11-23　リポジトリを非公開にする（App Store に出す前に）

- 理由：有料アプリのソースコードを、誰でも見られる状態にしないため。
- GitHub の無料プランでは、非公開にすると GitHub Pages の公開が止まる。そのため、先に公開先を Cloudflare（Workers の静的アセット。無料で非公開のリポジトリから公開できる）に移し、そのあとで非公開にする。
- 移すと変わるもの：
  - URL（アプリの中のプライバシーポリシー、サポートページ、手順書、App Store に登録する URL）
  - ブラウザに保存したデータ（サイトの住所ごとなので引き継がれない。書き出し → 新しい URL で読み込み）
  - 問い合わせ先（非公開にすると GitHub の Issues は一般の人が開けない）
- 未定：独自ドメインを使うか、問い合わせ先をどうするか。

## 2026-11-23　Web 版で課金するなら、本人を見分ける仕組みとサーバーが要る

- iOS・Android は、ストアのアカウント（Apple ID・Google アカウント）が本人の代わりになるので、ログインもサーバーも要らない。
- Web にはそれがないので、誰が払ったかを見分ける仕組み（メールに届くリンクを押すだけの軽いログインでよい）と、支払いを確かめるサーバー（Stripe の通知を受ける。Cloudflare に置ける）が要る。
- 当面、Web 版は無料の体験版なので作らない。

## 2026-11-23　Android 版も作る。住所の公開は了承

- Android 版も作る（iOS 版と同じ中身を使う）。違いと進め方は [`android.md`](android.md)。
- Google Play では、課金するアプリの開発者の住所が公開される。これを了承した。
- Android の実機はある。
- 確認したこと：**iOS には、Android のような「12人・14日」の公開前テストの義務はない。** 2026年10〜11月の TestFlight の不具合は、決まりではなく不具合とみられる（くわしくは [`roadmap.md`](roadmap.md) の段階1）。

## 2026-11-23　iOS アプリは、ログインなしで課金する

### 決めたこと

Mimic の iOS アプリでは、ログイン機能を作らない。App Store の月額課金（利用者の Apple ID に結びつく）だけで課金し、サーバーも使わない。

### 理由

- アプリは、利用者の Apple ID が月額課金中かどうかを、iPhone の中で Apple の仕組み（StoreKit）を使って確かめられる。ログインもサーバーも要らない。
- App Store の審査ガイドライン 5.1.1(v) は「アカウントが必要な機能がないなら、ログインなしで使えるようにすること」としている。
- プロジェクトや録音は端末の中だけに保存するので、アカウントで管理するデータがない。
- サーバー代がかからない。アカウントの削除機能や「Apple でログイン」など、アカウントに関わる審査の条件もなくなる。個人情報を集めないので、App Store のプライバシー欄を「データの収集なし」にできる。

### これでできること

- 機種変更や iPad でも、同じ Apple ID なら「購入を復元」で有料のまま使える。
- オフラインでも、端末に残っている購入情報で課金状態を確かめられる。
- 更新・解約・返金は Apple が処理する。

### 審査で必要になるもの

- 「購入を復元」ボタン
- 購入画面での価格・期間・自動更新の説明
- 利用規約（Apple 標準の EULA）とプライバシーポリシーへのリンク

### この決め方の弱いところ

- Web 版や Android 版と課金を共有できない。Web 版は無料の体験版という位置づけにする。
- プロジェクトはその iPhone の中だけに残る。機種変更のときは、iPhone のバックアップから戻すか、「書き出し」と「読み込み」で移す。アプリを消すと、課金は復元できるが、プロジェクトは戻らない。

### 見直すとき

- Web 版や Android 版でも同じ課金を使いたくなったとき（ログインと、RevenueCat などの課金をまとめるサービスを足す）
- プロジェクトをクラウドで同期したくなったとき

### どこに書いてあるか

- 課金の仕組み：`app/src/app.js`（`@capgo/native-purchases` で StoreKit 2 を使う）
- 月額課金の製品 ID：`mimic.premium.monthly`
- 公開までの手順：`app/README.md`

## 2026-11-22〜23　あわせて決まったこと

- iOS アプリを本命にする。個人で出す（App Store の販売者欄には本名が出る）。
- アプリの見た目は、デザイン案 B Pocket から始める。今後改良していく前提。
- 無料はプロジェクト1つまで。プレミアム（月額500円）は無制限。
- 解約しても、作ったプロジェクトは開いて練習できる。新しく作るのだけ止める。オフラインで更新を確かめられないときは、期限から3日の猶予を残す。
- 新しい機能は Speak Back（`english-practice2.html`）に追加する。Kodama と Mimic（`mimic/`）は、UI・UX を考える場所にする。
- `main` ブランチで管理する。
