# Kodama

英語を話すと、すぐに自分の声で聞き返せる発音練習アプリです。ブラウザだけで動き、サーバーは必要ありません。

## 使い方

1. ページを開いて、真ん中の丸をタップします（初回はマイクの許可を求められます）。
2. 英語で話します。
3. 話し終えて黙ると、丸のまわりに線が伸び、一周すると自分の声が流れます。
4. 流れ終わると、また聞き取りに戻ります。2 に戻って、何度でも言い直せます。

### 練習する英文（任意）

「練習する英文を選ぶ」から、言いたい英文を入力するか、例文（日常・旅行・仕事・L と R・TH・B と V など）から選べます。

英文を決めて話すと、聞き取られた結果と照らし合わせて、**伝わらなかった単語に波線**が付き、「5語中 4語が伝わりました」のように表示されます。「今回の練習」には毎回のスコアが残るので、言い直すたびに良くなっていくのが分かります。

※ この判定には「話した英語を文字にする」をオンにする必要があります。

### モード

- **自動**: 話し始めと話し終わりを自動で判定します。手を使わずに「話す → 聞く → 話す」を繰り返せます。
- **手動**: 丸をタップで録音開始、もう一度タップで止めて再生します。周りがうるさい場所向けです。

### ボタン

- **もう一度聞く**: さっきの発音をもう一度再生します。
- **お手本を聞く**: 練習する英文（なければ聞き取られた英文）を、ブラウザの読み上げ音声で再生します。
- **保存**: 残したい発音だけ、この端末のブラウザに保存します。保存しなかった発音は、ページを閉じると消えます。保存したものはダウンロード（WAV）や削除ができ、削除してもすぐなら「元に戻す」で戻せます。

### 再生のしかた（丸の下のボタン）

- **速さ**: 押すたびに 0.7 → 0.85 → 1 → 1.15 倍と変わります。声の高さは変わりません。
- **2回聞く**: 自分の声を2回続けて流します。
- **お手本も流す**: 自分の声のあとに、お手本の発音を続けて流します。聞き比べに便利です。

### マイクと文字起こしの設定

- **声への反応**: 話していないのに録音が始まるなら「にぶい」へ、声に反応しないなら「敏感」へ。
- **話し終わりの待ち時間**: 黙ってから再生するまでの時間（0.4〜2.0 秒）。
- **話した英語を文字にする**: 聞き取られた英文を表示します。
- **英語の種類 / お手本の声**: 文字起こしと読み上げに使う英語を選べます。

### オフラインで使う

一度開いたあとは、インターネットにつながっていなくても使えます。iPhone では「ホーム画面に追加」して使うのがおすすめです（アプリのように開けて、保存した発音も消されにくくなります）。

| 機能 | オフライン |
|---|---|
| 録音・自分の声の再生 | ○ |
| 練習する英文・保存した発音 | ○ |
| お手本の声 | ○（端末に入っている声を使います） |
| 文字起こし・単語チェック | ×（つながると自動で戻ります） |

### そのほかの気配り

- 自動モードで練習している間は、スマホの画面が暗くならないようにしています。
- 別のアプリやタブに切り替えると、自動で一時停止します（知らないうちに録音しないように）。
- 3 分間声がないと、自動で一時停止します。
- スマホのホーム画面に追加すると、アプリのように開けます。
- キーボード: Space で録音・停止、R でもう一度聞く、M でお手本、S で保存。

## Mimic（デザイン案）

`mimic/` は、Speak Back（`english-practice2.html`）の機能をそのまま使って、見た目と使い勝手を変えた試作です。`mimic/index.html` で3案を見比べられます。

| 案 | 向いている人 | 特徴 |
|---|---|---|
| A Studio（`mimic/studio.html`） | パソコン・iPad でプロジェクトを作り込む人 | 波形を中心に1画面で全部見える。暗めの配色 |
| B Pocket（`mimic/pocket.html`） | iPhone で片手で練習する人 | 録音ボタンを画面下のまん中に。下のタブで切り替え。ダークモード対応 |
| C Phrase（`mimic/phrase.html`） | フレーズを順番に身につけたい人 | 印をフレーズのカードに。「用意 → 聞く → まねる」の順に進む |

- 仕組み（`mimic/mimic.js`）は Speak Back からそのままコピーしたものです。新しい機能は Speak Back に追加し、決まった案に取り込みます。
- データは Speak Back とは別に保存します。Speak Back で「書き出し」したファイルを読み込めます。

## Mimic の iOS アプリ

`app/` は、B Pocket のデザインを iPhone アプリにしたものです。Mac がなくても、Codemagic（クラウドの Mac）でビルドして App Store に出せます。手順は [`app/README.md`](app/README.md) にまとめています。

- 課金：ログインなしで Apple ID の月額課金を使う。無料はプロジェクト1つ、プレミアムは無制限
- 解約しても、作ったプロジェクトは消えない
- オフラインでも練習できる

## 対応ブラウザと注意点

| | 録音・再生 | 文字起こし | お手本の読み上げ |
|---|---|---|---|
| Chrome / Edge（PC） | ○ | ○ | ○ |
| Safari（Mac / iPhone / iPad） | ○ | △ | ○ |
| Chrome（Android） | ○ | △ | ○ |
| Firefox | ○ | × | ○ |
| LINE などのアプリ内ブラウザ | △ | × | △ |

- **マイクは https が必須です。** GitHub Pages は https なのでそのまま使えます。
- **LINE などで共有されたリンクは、Safari や Chrome で開き直してください。** アプリ内ブラウザではマイクが使えないことがあります（画面にも案内が出ます）。
- **文字起こしはブラウザの機能（Web Speech API）を使います。** Chrome では音声が Google のサーバーに送られて処理されるため、インターネット接続が必要です。録音と再生だけなら、音声はどこにも送られません。
- **スマホでは文字起こしが初期状態でオフです。** スマホのブラウザは、録音と文字起こしで同じマイクを同時に使えないことがあり、声に反応しなくなる場合があるためです。設定でオンにして試せます。
- **イヤホンがおすすめです。** スピーカーでも使えます（再生中は聞き取りを止めているので、自分の声を拾って無限に繰り返すことはありません）。

## GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開きます。
2. **Build and deployment** の Source を **Deploy from a branch** にします。
3. Branch に `main` と `/ (root)` を選んで **Save** します。
4. 1〜2 分で `https://<ユーザー名>.github.io/english-lisening/` に公開されます。

ビルドは不要です。リポジトリのファイルをそのまま配信します。

## ローカルで動かす

`localhost` は https でなくてもマイクが使えます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（HTML ファイルを直接開くと、ブラウザによってはマイクが使えません）。

## しくみ

- マイク入力を AudioWorklet で受け取り、音量から話し始めと話し終わりを判定します。周りの雑音レベルは自動で追いかけます。
- 声を検知する少し前（0.35 秒）の音も残しているので、語頭が切れません。
- 前後の無音を切り詰め、音量をそろえた WAV を作って、すぐ再生します。
- 練習する英文との照合は、短縮形（I'd と I would など）や数字（2 と two）をそろえてから、単語の並びを比べています。
